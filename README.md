# Econo Lift Product Brochure (Concept)

Concept mockup of a 4-page, letter-size (8.5" × 11") bi-fold product brochure for Econo Lift, styled to match the new econolift.com (Open Sans; brand navy #24436a, blue #2791ce, red #d92424; series colors for Surge, Draft, Double Charge and Jolt).

**Pages:** 1 Front cover · 2 Inside left (series finder + Meridian) · 3 Inside right (Surge, Draft, Double Charge, Jolt) · 4 Back cover (warranty, build quality, dealer CTA)

## View / print
Open `index.html` in a browser. To make a PDF, print with paper size Letter, margins None, and "Background graphics" on.
